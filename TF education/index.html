📌 업로드 안내
  • PDF에 문제 해결, Troubleshooting, Error Code 섹션이 있으면 자동 추출됩니다.
  • 스캔 이미지 PDF는 OCR로 처리합니다 (서버에 pytesseract + Tesseract-OCR 필요).
  • 장비명·모델명을 입력하면 해당 장비로 태깅되어 장비별 검색에 활용됩니다.
  • 같은 장비/모델로 재업로드하면 이전 자료가 교체됩니다.
  • 서버 재시작 시 업로드 자료는 초기화됩니다.
