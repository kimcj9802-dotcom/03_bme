백엔드 만들기
FastAPI로 단일 파일 백엔드 app.py 를 만들어줘.
- 역할: 프론트가 보낸 {question, context} 를 받아, spark-2 AI 모델에 보내 답을 돌려준다.
- 모델 호출: POST http://121.138.151.6:11434/api/chat , 모델 "qwen3.6:35b-a3b" , stream:true
- 시스템 프롬프트: "참고 자료에만 근거해 한국어로 간결히 답한다. 자료에 없으면 '확인되지 않습니다'라고 한다."
- 엔드포인트: POST /api/chat (SSE 스트리밍으로 토큰 전송), GET /health
- CORS 허용, 포트 8000, httpx 사용.
- 중요: 프론트(HTML)가 ollama를 직접 호출하지 않고 반드시 이 백엔드를 거치게 설계할 것.

 프론트(화면) 만들기
단일 파일 index.html 프론트를 만들어줘.
- 구성: 질문 입력창 + 참고자료 입력칸 + 답변 영역 + 연결상태 표시등.
- 맨 위에 주소를 한 줄로 모아둘 것: const BE = "http://127.0.0.1:8000";  (이후 모든 호출은 BE + "/api/chat" 처럼 이 변수만 사용)
- 중요: 호출은 오직 내 백엔드(BE)로만 한다. ollama(11434) 직접 호출 절대 금지.
- (개인 과제에서 새 엔드포인트를 추가하더라도, 화면은 별도 안내가 없으면 공통 ①의 /api/chat(SSE)를 그대로 호출한다.)
- POST로 {question, context} 전송, SSE 응답을 실시간으로 답변 영역에 표시.
- 시작 시 GET BE + "/health" 로 연결 확인 후 상태 표시.
- 한국어 UI, 깔끔하게.

실행 (터미널)
pip install fastapi uvicorn httpx
# (먼저 포트가 비었는지 확인) — 아래가 응답하면 8000은 이미 사용중:curl -s http://127.0.0.1:8000/healthuvicorn app:app --port 8000          # ← 이 창은 켜둔 채로 둠(백엔드)
# 그 다음 index.html 을 더블클릭해 브라우저로 열기
