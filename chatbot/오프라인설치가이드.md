# 의료기기 RAG 챗봇 — 폐쇄망 설치 가이드

## 필요 파일 목록 (인터넷 PC에서 준비)

| 파일 | 다운로드 위치 | 용량 |
|------|--------------|------|
| Node.js 설치파일 (Windows) | https://nodejs.org → LTS 버전 `.msi` | ~30MB |
| Ollama 설치파일 (Windows) | https://ollama.com/download/windows | ~60MB |
| AI 모델 파일 (`qwen2.5:1.5b`) | Ollama 설치 후 `ollama pull qwen2.5:1.5b` | ~900MB |
| 챗봇 앱 전체 폴더 (`chatbot/`) | 이 폴더 전체 복사 | ~100MB |

---

## STEP 1 — 인터넷 PC에서 준비

### 1-1. Node.js 다운로드
1. https://nodejs.org 접속
2. **LTS 버전** Windows Installer (`.msi`) 다운로드

### 1-2. Ollama 및 AI 모델 준비
1. https://ollama.com/download/windows 에서 `OllamaSetup.exe` 다운로드
2. 인터넷 PC에 Ollama 설치 후 명령 프롬프트에서:
   ```
   ollama pull qwen2.5:1.5b
   ```
3. 모델 파일 위치 확인 (기본값):
   ```
   C:\Users\[사용자명]\.ollama\models\
   ```
4. 해당 폴더 전체를 USB에 복사

### 1-3. 챗봇 앱 복사
- `chatbot` 폴더 전체를 USB에 복사 (`node_modules` 포함)

---

## STEP 2 — 폐쇄망 서버에 설치

### 2-1. Node.js 설치
1. USB의 Node.js `.msi` 파일 실행
2. 기본 설정으로 설치 완료

### 2-2. Ollama 설치
1. USB의 `OllamaSetup.exe` 실행
2. 기본 설정으로 설치 완료

### 2-3. AI 모델 복사
1. USB의 `.ollama\models\` 폴더를 서버의 다음 경로에 복사:
   ```
   C:\Users\[사용자명]\.ollama\models\
   ```

### 2-4. 챗봇 앱 복사
1. USB의 `chatbot` 폴더를 서버에 복사 (예: `C:\chatbot\`)

### 2-5. 설정 파일 수정
`chatbot\.env` 파일을 메모장으로 열어 비밀번호 변경:
```
ADMIN_PASSWORD=원하는비밀번호
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:1.5b
PORT=3000
```

---

## STEP 3 — 서버 실행

### Ollama 시작
- 시작 메뉴에서 **Ollama** 실행 (시스템 트레이에 아이콘 생성)
- 또는 명령 프롬프트: `ollama serve`

### 챗봇 서버 시작
명령 프롬프트에서:
```
cd C:\chatbot
node server.js
```

성공 시 출력:
```
🏥 의료기기 RAG 챗봇 (폐쇄망 모드)
   사용자: http://localhost:3000
   관리자: http://localhost:3000/admin
   Ollama: ✅ 연결됨 (qwen2.5:1.5b)
```

---

## STEP 4 — 메뉴얼 등록 (최초 1회)

1. 브라우저에서 `http://localhost:3000/admin` 접속
2. 비밀번호 입력 (`.env`에 설정한 값)
3. PDF 메뉴얼 업로드 (드래그앤드롭 또는 클릭)
4. 처리 완료 확인 후 `http://localhost:3000` 에서 챗봇 사용

---

## 사용 방법

| 역할 | 접속 주소 |
|------|----------|
| 간호사·임상병리사 | `http://[서버IP]:3000` |
| 관리자(의공) | `http://[서버IP]:3000/admin` |

> 같은 네트워크의 다른 PC에서 접속하려면 서버 IP 주소 사용

---

## 자동 시작 설정 (선택사항)

서버 재시작 시 자동으로 챗봇이 실행되도록 설정하려면 관리자에게 문의하세요.

---

## 문제 해결

| 증상 | 해결 방법 |
|------|----------|
| "AI 서버 연결 안 됨" | Ollama가 실행 중인지 확인 |
| 챗봇이 느림 | 정상 (CPU 전용 모드, 응답 10~30초 소요) |
| 관리자 로그인 안 됨 | `.env` 파일의 `ADMIN_PASSWORD` 확인 |
| PDF 업로드 실패 | PDF 파일 크기 50MB 이하인지 확인 |
