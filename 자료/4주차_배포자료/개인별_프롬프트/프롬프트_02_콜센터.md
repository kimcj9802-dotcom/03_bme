## 02. (콜센터) — 콜센터 · 공유 API 붙이기 프롬프트

### 1. 한 줄 목표

내 콜센터 안내 챗봇의 채팅/임베딩 주소를 공유 게이트웨이(`:11500`)로 맞추고, 이제 필요 없어진 생각 끄기·답변 길이 처리 코드를 정리한 뒤, "자료에 없으면 답하지 않는다"는 거절 규칙을 시스템 프롬프트에 확실히 넣는다. — 손으로 고치지 말고, 아래 프롬프트를 AI 코딩 도구에 그대로 붙여넣어 시킵니다.

---

### 2. 복붙 프롬프트 (그대로 붙여넣기)

```text
너는 내 파이썬 앱을 수정하는 코딩 도우미야. 이 앱은 병원 콜센터 안내 챗봇이고,
이용안내(주차·면회·증명서 등)를 임베딩으로 검색해서 그 자료에만 근거해 답하는 RAG 구조야.
아래 작업을 순서대로 하고, 각 단계에서 무엇을 왜 바꿨는지 한 줄씩 설명해줘.

1) 모델 주소를 공유 게이트웨이로 통일
   - 본인 앱의 app.py 맨 위에 있는 두 개의 URL 상수를 찾아줘.
     하나는 채팅용(약 12번째 줄, 이름은 대개 OLLAMA_URL, 끝이 /api/chat),
     다른 하나는 임베딩용(약 13번째 줄, 이름은 대개 EMBED_URL, 끝이 /api/embeddings)이야.
   - 두 줄 모두 호스트/포트를 "http://121.138.151.6:11500" 으로 바꿔줘.
     즉 채팅은 http://121.138.151.6:11500/api/chat,
     임베딩은 http://121.138.151.6:11500/api/embeddings 가 되어야 해.
     (임베딩까지 :11500으로 바꿔야 RAG 검색이 정상 동작함. 두 줄 다 꼭 확인.)
   - 만약 이미 두 줄 다 :11500이면 그대로 두고 "이미 게이트웨이로 설정됨"이라고만 알려줘.
   - 모델명 상수(대개 MODEL, 약 14번째 줄)는 절대 바꾸지 마. 게이트웨이가 모델명을 알아서 맞춰줘.

2) 게이트웨이가 대신 처리하는 코드 정리
   - 게이트웨이가 think:false(생각 끄기)와 답변 길이 상한(num_predict)을 자동으로 넣어주니까,
     본인 앱 코드에서 요청 본문(payload/options)에 "think", "num_predict" 를 직접 넣던 부분이 있으면
     지워줘. 응답에서 <think>...</think> 를 잘라내던 후처리 코드가 있으면,
     한 줄짜리 안전망(예: token 정리) 정도만 남기고 나머지는 정리해도 좋아.
   - 단, 주차요금 계산 로직과 개인정보(주민번호·환자번호 등) 차단 로직은 절대 건드리지 마.
     이 두 기능은 그대로 유지해야 해.

3) "자료에 없으면 거절" 규칙 확인·보강
   - 본인 앱의 시스템 프롬프트(모델에게 주는 지침 문자열)를 찾아줘.
   - 검색된 안내 자료에 근거가 없는 질문에는 지어내지 말고
     "확인되지 않습니다. 안내 자료에 없는 내용입니다." 라고 답하도록
     시스템 프롬프트에 한 문장을 넣거나, 이미 있으면 그대로 두고 알려줘.
   - 요금·시간 같은 숫자는 검색된 자료의 값만 쓰고, 없으면 임의로 만들지 말라는 문장도 함께 넣어줘.

작업이 끝나면 바뀐 파일과 줄 번호를 요약해서 보여줘.
```

---

### 3. 이 프롬프트가 실제로 바꾸는 것

- 채팅 URL(app.py 약 12행)과 임베딩 URL(약 13행) **두 줄 모두**를 `:11500` 게이트웨이로 맞춰, 답변과 RAG 검색이 함께 정상 동작합니다.
- `think`·`num_predict`를 직접 넣던 코드와 `<think>` 후처리를 정리 — 게이트웨이가 대신 처리하므로 코드가 깔끔해집니다.
- 시스템 프롬프트에 "자료에 없으면 확인되지 않습니다" 거절 규칙을 확인·추가해, 없는 요금/시간을 지어내지 않게 합니다.
- 주차요금 계산·개인정보 차단·모델명 상수는 건드리지 않아 기존 기능이 그대로 유지됩니다.

---

### 4. 붙인 뒤 확인

1) 게이트웨이 살아 있는지 먼저 확인
```bash
curl http://121.138.151.6:11500/health
```
`ok` 또는 상태 정보가 돌아오면 정상. 응답이 없으면 강사에게 알리세요.

2) 앱 기동 (앱 폴더 안에서)
```bash
python -m uvicorn app:app --port 8000
```
첫 질문 때 `🔨 DOCS 임베딩 중...` → `✅ 8개 청크 캐시 완료`가 뜨면 임베딩이 게이트웨이로 붙은 것.

3) 대표 질문 1개로 끝까지 확인
```bash
curl -N -X POST http://127.0.0.1:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"A주차장에 2시간 세우면 주차비가 얼마예요?"}'
```
기대 답: **4,000원**. 답변에 `<think>`나 혼잣말 추론이 섞이지 않고 본문만 깔끔하게 나오면 성공.

### 5. 안전

- 테스트는 **더미(가짜) 질문**으로만. 예: "외래 진료시간 알려주세요", "면회 시간이 언제예요".
- 환자번호·주민번호·진단명 등 개인정보는 **절대 입력창에 넣지 마세요.** 앱이 자동 차단하지만 1차 책임은 입력하는 사람에게 있습니다.
- 안내 자료를 추가할 때도 대외비·내부 운영 정보는 넣지 말고 공개 안내문 수준만.
- 거절 규칙: 자료에 없는 내용은 "확인되지 않습니다"로 답하도록 두고, 요금·시간은 최종 안내 전 실제 규정으로 한 번 더 확인하세요.
- `:11500`은 모두가 함께 쓰는 GPU 1개입니다. 대량·반복 질문 금지, 답이 나온 뒤 다음 질문을 보내세요.
