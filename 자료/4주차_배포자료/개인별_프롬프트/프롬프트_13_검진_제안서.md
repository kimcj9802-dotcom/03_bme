## 검진-제안서. (부서) — 제안서 · 공유 API 붙이기 프롬프트

### 1. 한 줄 목표

내 제안서 생성기(비-AI 앱)에 **"AI 문구 생성" 기능 한 개(`/api/ai-copy`)** 를 붙인다. 즉 표준 `urllib`로 공유 게이트웨이(`:11500`)를 부르는 연결 코드를 추가하고, 게이트웨이가 생각 끄기·답변 길이를 자동 처리하니 그 처리 코드는 넣지 않으며, "자료에 없으면 지어내지 않는다"는 거절 규칙을 시스템 프롬프트에 확실히 넣는다. — 손으로 고치지 말고, 아래 프롬프트를 AI 코딩 도구에 그대로 붙여넣어 시킵니다.

---

### 2. 복붙 프롬프트 (그대로 붙여넣기)

```text
너는 내 파이썬 앱을 수정하는 코딩 도우미야. 이 앱은 엑셀(검진 항목·수가)을 읽어
건강검진 제안서 PDF를 만드는 4단계 마법사이고, 지금은 AI 기능이 전혀 없어.
requests·httpx 같은 외부 라이브러리도 안 쓰고 표준 http.server만 써.
오늘 할 일은 "AI 문구 생성" 엔드포인트 한 개를 새로 붙이는 거야.
아래를 순서대로 하고, 각 단계에서 무엇을 왜 바꿨는지 한 줄씩 설명해줘.

0) 대상 파일 확인
   - 본인 앱의 core/http_handler.py 를 열어줘. 여기 하나만 고칠 거야.
   - 이 파일에는 이미 Handler 클래스와 do_POST, 그리고 handle_generate 같은
     handle_... 메서드들, send_json 응답 헬퍼가 있어. 그것들은 그대로 두고 추가만 해.

1) import 추가
   - 파일 상단 import 묶음(import json 근처)에 아래 한 줄을 추가해줘.
       import urllib.request
     (json 과 urllib.parse 는 이미 있을 테니 중복 추가하지 마.)

2) 게이트웨이 호출 함수 추가 (표준 urllib 사용, 외부 라이브러리 금지)
   - 파일 아래쪽 모듈 레벨(클래스 밖)에 게이트웨이 주소 상수와 호출 함수를 추가해줘.
     주소는 반드시 공유 게이트웨이 :11500 을 써야 해.
       GATEWAY = "http://121.138.151.6:11500"

       def ai_write(system: str, user: str) -> str:
           body = {
               "model": "qwen3.6:35b-a3b",
               "messages": [
                   {"role": "system", "content": system},
                   {"role": "user",   "content": user},
               ],
               "stream": False,
           }
           req = urllib.request.Request(
               f"{GATEWAY}/api/chat",
               data=json.dumps(body).encode("utf-8"),
               headers={"Content-Type": "application/json"},
           )
           with urllib.request.urlopen(req, timeout=120) as r:
               data = json.loads(r.read())
           return data["message"]["content"]
   - 중요: 이 body 안에 think(생각 끄기)나 num_predict(길이 상한)를 절대 넣지 마.
     게이트웨이가 그 두 가지와 모델명 정규화를 자동으로 처리하니까 우리 코드는 깔끔하게 둬.
     응답에서 <think>...</think> 를 잘라내는 후처리 코드도 넣지 마 (게이트웨이가 이미 막아줌).

3) 시스템 프롬프트와 사용자 프롬프트 추가 (여기가 오늘의 핵심)
   - 파일 상단(import 아래) 모듈 레벨에 아래 두 개를 추가해줘.
       SYSTEM_PROMPT = """당신은 병원 건강검진센터의 제안서 문구를 쓰는 작가입니다.
       다음 규칙을 반드시 지키세요.
       - 톤: 정중하고 신뢰감 있는 영업 제안 톤. 과장·홍보성 미사여구 금지.
       - 길이: 인사말 2~3문장 + 패키지 소개 2~3문장. 전체 5문장 안팎.
       - 절대 금지: 수치·검진 항목 수·가격·실적을 스스로 지어내지 말 것.
       - 자료로 받지 않은 숫자나 항목은 확인되지 않은 값이므로 쓰지 말고
         [확인 필요] 라고만 표시할 것.
       - 출력은 완성된 한국어 문단만. 머리말('네, 작성하겠습니다' 등)·설명·목록 금지."""

       def build_user_prompt(customer: str, year: str, exam_type: str) -> str:
           return (
               "아래 정보로 건강검진 제안서 도입 문구를 작성해 주세요.\n"
               f"- 고객사명: {customer}\n"
               f"- 검진 연도: {year}\n"
               f"- 검진 타입: {exam_type}\n"
           )
   - 이 앱은 숫자 근거가 반드시 엑셀/코드에서 나와야 하니까,
     "지어내지 말 것 / [확인 필요] 표시" 이 거절 규칙은 절대 지우지 말고 확실히 넣어줘.
     이미 비슷한 SYSTEM_PROMPT가 있으면 이 거절 규칙이 들어 있는지 확인만 하고 없으면 보강해줘.

4) 라우팅 한 줄 + 핸들러 메서드 추가
   - do_POST 안의 분기(/api/generate, /api/generate-final 을 받는 곳)에 아래를 끼워줘.
       elif path == "/api/ai-copy":
           self.handle_ai_copy()
   - Handler 클래스 안, 다른 handle_... 메서드들과 같은 들여쓰기 높이에 아래 메서드를 추가해줘.
       def handle_ai_copy(self) -> None:
           try:
               length  = int(self.headers.get("Content-Length", 0))
               payload = json.loads(self.rfile.read(length) or b"{}")
               customer  = str(payload.get("customer", "")).strip()
               year      = str(payload.get("year", "")).strip()
               exam_type = str(payload.get("exam_type", "")).strip()
               system = SYSTEM_PROMPT
               user   = build_user_prompt(customer, year, exam_type)
               copy = ai_write(system, user)
               self.send_json(200, {"copy": copy})
           except Exception as err:
               self.send_json(500, {"error": str(err)})
   - send_json 은 이 앱에 이미 있는 헬퍼니까 새로 만들지 말고 그대로 써.

5) 절대 건드리지 말 것
   - 기존 PDF 생성(/api/generate, /api/generate-final), 엑셀 읽기, 표·수가·이미지 합치기 로직은
     한 줄도 바꾸지 마. AI는 "문장 초안"만 담당하고 숫자 근거는 늘 엑셀/코드에서 나와.
   - Node.js 렌더러 부팅 코드도 건드리지 마 (오늘 작업과 무관한 기존 의존성이야).

작업이 끝나면 바뀐 파일과 추가된 줄 위치를 요약해서 보여줘.
```

---

### 3. 이 프롬프트가 실제로 바꾸는 것

- `core/http_handler.py`에 표준 `urllib`로 게이트웨이 `:11500`을 부르는 `ai_write()`와 `/api/ai-copy` 엔드포인트가 새로 생깁니다(비-AI 앱에 AI 문구 기능 1개 추가).
- `ai_write` 본문에는 `think`·`num_predict`를 넣지 않고 `<think>` 후처리도 넣지 않습니다 — 게이트웨이가 생각 끄기·길이 상한·모델명 정규화를 자동 처리하므로 코드가 깔끔합니다.
- `SYSTEM_PROMPT`에 "수치·항목을 지어내지 말 것 / 자료에 없으면 [확인 필요] 표시" 거절 규칙을 확인·보강해, 없는 검진 항목 수·가격을 만들어내지 않게 합니다.
- 기존 PDF 생성(`/api/generate`)·엑셀·Node.js 렌더러는 손대지 않아 회귀 없이 그대로 동작합니다.

### 4. 붙인 뒤 확인

1) 게이트웨이 살아 있는지 먼저 확인
```bash
curl http://121.138.151.6:11500/health
```
정상 응답(상태 정보)이 오면 통과. 안 오면 강사에게 주소를 확인하세요.

2) 앱 기동 (앱 폴더 안에서)
```bash
python3 server.py
```
브라우저가 `http://127.0.0.1:8765` 로 열립니다.
> 만약 `RuntimeError: Node.js 렌더링 서버 시작 실패`로 멈추면, 그건 이 앱 원래의 PDF 렌더러(노드 번들) 의존성 문제이지 오늘 추가한 AI 기능과는 무관합니다. 폴더에서 `npm install`이 끝나 있어야 앱이 뜹니다.

3) 대표 질문 1개로 끝까지 확인 (버튼 없이 백엔드만으로 OK)
```bash
curl -X POST http://127.0.0.1:8765/api/ai-copy \
  -H "Content-Type: application/json" \
  -d '{"customer":"가나물산","year":"2026","exam_type":"A타입"}'
```
`{"copy":"..."}` 형태로 정중한 한국어 도입 문구(5문장 안팎)가 오면 성공. 답변에 `<think>`나 혼잣말 추론이 섞이지 않고, 주지 않은 항목 수·가격을 지어내지 않으면 정상입니다.

---

### 5. 안전

- 테스트는 **더미·비식별 값**으로만. 예: 고객사 `가나물산`, 연도 `2026`, 타입 `A타입`. 실제 고객사명·계약·수가·실적은 모델에 넣지 마세요.
- 환자정보·대외비 입력 금지. AI는 "문장 초안"만, **숫자 근거는 반드시 엑셀/코드**에서 나옵니다. 생성 문구의 항목 수·가격은 사람이 최종 검증하세요.
- 거절 규칙: 자료로 주지 않은 값은 지어내지 말고 `[확인 필요]`로 표시하도록 시스템 프롬프트에 유지하세요. 생성 문구는 편집 가능해야 하며, 모델 출력 그대로를 고객에게 보내지 마세요.
- `:11500`은 모두가 함께 쓰는 GPU 1개입니다. 버튼·요청을 연타하지 말고 응답을 기다린 뒤 다시 호출하세요.
