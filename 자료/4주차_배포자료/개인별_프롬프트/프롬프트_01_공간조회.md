## 01. 시설팀 — 공간조회 · 공유 API 붙이기 프롬프트

### ① 한 줄 목표
내 공간조회 챗봇(C 조회 · RAG)의 **모델 주소를 공유 게이트웨이(:11500)** 로 바꾸고, 게이트웨이가 대신 처리해 주는 옵션 코드를 정리한 뒤, "자료에 없으면 확인되지 않습니다" 거절 규칙을 시스템 프롬프트에 넣는다. (손으로 안 고치고 AI에게 시킨다.)

---

### ② 복붙 프롬프트 (Claude Code에 그대로 붙여넣기)

```text
너는 내 코딩 파트너야. 아래 작업을 순서대로 해줘. 나는 코드를 잘 모르니, 바꾼 파일과 바꾼 줄을 짧게 설명해줘.

[내 앱 배경]
- 이건 원내 공간(기계실·세미나실·약제부 등)을 자연어로 조회하는 챗봇이야. C(조회·검색) 형이고, 임베딩 검색(RAG)으로 의미가 가까운 공간을 찾아 근거와 함께 답해.
- 구조는 3단이야: 프론트(index.html) → 내 백엔드(FastAPI, app.py) → 공유 게이트웨이. 모델 호출은 오직 백엔드(app.py)만 하고, 프론트는 절대 모델 주소를 직접 부르지 않아. 이번 작업은 백엔드 app.py만 건드려.

[작업 1] 모델 주소를 공유 게이트웨이로 변경
- 본인 앱의 백엔드(app.py)에서 "모델 주소를 지정하는 줄"을 전부 찾아줘. 보통 상단 설정 구역에 OLLAMA_URL 같은 변수로 있고, IP가 121.138.151.6 이고 포트가 11434(raw 포트)로 되어 있어.
- 이 앱은 채팅(/api/chat)과 임베딩(/api/embeddings)을 둘 다 쓰기 때문에 주소가 2~3곳에 흩어져 있을 수 있어. IP는 그대로 두고, 포트 11434를 전부 11500으로 바꿔줘. 한 곳도 빠지면 안 돼. 바꾼 자리를 전부 알려줘.
  예: http://121.138.151.6:11434  →  http://121.138.151.6:11500

[작업 2] 게이트웨이가 대신 처리하는 코드 정리
- 이제 게이트웨이(:11500)가 추론 누출 차단(think:false), 답변 길이 상한(num_predict), 모델명 자동 보정을 알아서 해줘.
- 그러니 app.py에서 요청 본문(payload)에 우리가 직접 넣던 think 관련 처리, num_predict/max_tokens 강제 지정, <think> 태그를 잘라내던 후처리 코드가 있으면, 있는지 먼저 확인하고 → 불필요해진 부분만 안전하게 정리해줘. (기능이 깨지지 않는 선에서만. 모델명 CHAT_MODEL/EMBED_MODEL 값은 그대로 둬.)
- 없으면 "해당 코드 없음"이라고만 알려주고 넘어가.

[작업 3] 거절 규칙을 시스템 프롬프트에 확인·추가
- app.py 안에서 모델에 보내는 "시스템 프롬프트(역할·규칙 문장)"를 찾아줘.
- 다음 규칙이 이미 있는지 확인하고, 없으면 자연스럽게 추가해줘:
  1) "제공된 공간 데이터에 근거가 없으면 지어내지 말고 '확인되지 않습니다'라고 답한다."
  2) "잠금번호·출입통제·상세 도면·비상금고 위치 등 보안시설 상세는 안내하지 않는다."
  3) "면적 합계 같은 집계 수치는 백엔드가 계산해 넘겨준 값만 인용하고, 숫자를 임의로 만들지 않는다."

[마무리]
- 바꾼 파일 목록과 핵심 변경 줄을 요약하고, 프론트(index.html)는 건드리지 않았는지 확인해줘.
```

> 아직 코드(app.py·index.html)가 없다면: 먼저 3주차 핸드아웃 **STEP 0 기본코드**로 출발선을 맞춘 뒤 위 프롬프트를 붙이세요. (참고: `3주차_강의_개인별/3주차_강의_01_공간조회.pdf` — STEP 0 + 프롬프트 1~7). 임베딩 계산에 numpy가 없으면 `pip install numpy`.

---

### ③ 이 프롬프트가 실제로 바꾸는 것
- 백엔드(app.py)의 모델 주소 포트를 `:11434` → `:11500` 으로 **전부** 교체 (채팅·임베딩 여러 곳).
- 게이트웨이가 대신 처리하게 된 think 차단·답변 길이 상한·`<think>` 잘라내기 코드를 확인 후 정리.
- 시스템 프롬프트에 "자료에 없으면 확인되지 않습니다" 거절 + 보안시설 상세 거절 + 집계값만 인용 규칙 추가.
- 프론트(index.html)는 손대지 않음 — 바뀌는 곳은 백엔드 한 군데뿐.

### ④ 붙인 뒤 확인
1) 게이트웨이 살아있는지:
```bash
curl http://121.138.151.6:11500/health
```
→ `ok`(또는 짧은 상태 JSON)가 오면 정상. 응답 없으면 강사에게 알리기.

2) 내 앱 기동 (app.py 폴더에서):
```bash
uvicorn app:app --host 0.0.0.0 --port 8000 --reload
# 새 터미널에서 프론트
python3 -m http.server 5500
```
→ 브라우저에서 `http://127.0.0.1:5500/index.html` 열기 (파일 더블클릭은 CORS로 막힘).

3) 대표 질문 1개:
> **"약제부 어디 있어?"** → 기대: **본관 2층, 259제곱미터** + 근거 칩(약제부), `<think>` 같은 혼잣말 없이 깔끔한 답.

터미널로 바로 쏘려면:
```bash
curl -X POST http://127.0.0.1:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"약제부 어디 있어?"}'
```
> `<think>`가 보이거나 답이 비면 대개 주소가 아직 `:11434`로 남은 것 — app.py에서 `11434`가 한 곳도 안 남았는지 다시 확인.

### ⑤ 안전
- **더미·비식별만.** 공간 데이터는 가짜 8칸(기계실·약제부 등)으로만. 실제 도면·정확한 면적·층별 배치 같은 시설 운영자료는 넣지 않기. 화면에 `Demo Mode(샘플 공간 데이터)` 배지 권장.
- **거절 규칙.** 보안시설 상세(잠금번호·출입통제·비상금고 위치 등)는 데이터에도 넣지 말고, 물어봐도 "보안시설 상세는 안내하지 않습니다"로 거절. 자료에 없으면 지어내지 말고 "확인되지 않습니다".
- **환자정보·대외비 입력 금지.** 입력창엔 환자 이름·등록번호·진단명·대외비 문서 절대 금지. 질문은 공간 단위 조회로만.
- **공유 GPU는 1대.** :11500 뒤 모델 서버는 여러 명이 함께 쓰므로 한 명씩 순서대로 시연하고, 느려도 기다리기. 내부 주소(`121.138.151.6:11500`)는 외부 공유 금지.
