## 06. 인사 — 복리후생 · 공유 API 붙이기 프롬프트

### ① 한 줄 목표

내 경조 복리후생 챗봇(A RAG)이 모델을 **공유 게이트웨이(`http://121.138.151.6:11500`)** 로만 부르게 바꾸고, 게이트웨이가 대신 처리해 주는 불필요한 코드를 정리한다. (손으로 고치지 말고 아래 프롬프트를 Claude Code에 그대로 붙여넣어 시킨다.)

---

### ② 복붙 프롬프트 (Claude Code에 그대로 붙여넣기)

```text
너는 내 FastAPI 기반 경조 복리후생 챗봇(A RAG) 코드를 수정하는 개발 도우미야.
아래 작업을 순서대로 하고, 끝나면 무엇을 바꿨는지 요약해줘.

[사전 확인]
- 먼저 본인 앱의 백엔드 코드(app.py 등)에서 모델 서버 주소가 들어간 줄을
  전부 찾아줘. "121.138.151.6", "11434", "11500", "ollama", "/api/chat",
  "/api/embeddings" 같은 문자열이 있는 줄이 대상이야.

[작업 1] 모델 주소를 공유 게이트웨이로 변경
- 본인 앱의 모델 주소 줄(예: OLLAMA_URL 같은 변수)의 포트를
  11434 → 11500 으로 바꿔줘. IP(121.138.151.6)는 그대로 둬.
  즉 최종값이 "http://121.138.151.6:11500" 이 되게 해줘.
- 만약 주소가 여러 군데 하드코딩돼 있으면, 파일 위쪽에
  OLLAMA_URL = "http://121.138.151.6:11500" 변수를 하나 만들고
  채팅 호출(/api/chat)과 임베딩 호출(/api/embeddings) 모두
  이 변수를 f-string으로 가져다 쓰게 통일해줘.
- 채팅/임베딩 모델명(예: qwen3.6:35b-a3b, bge-m3:latest)은 그대로 둬.
  게이트웨이가 실제 모델로 알아서 보정해주니까 건드리지 마.

[작업 2] 게이트웨이가 대신 처리하는 코드 정리
- 게이트웨이(:11500)가 추론 과정 차단(think:false), 답변 길이 상한,
  모델명 보정을 자동으로 해줘. 그래서 본인 앱의 모델 호출 payload에
  아래 옵션이 박혀 있으면 지워줘:
    · "think": false 같은 think 관련 옵션
    · options 안의 "num_predict" (답변 길이 상한) 설정
    · 응답에서 <think>...</think> 를 정규식으로 잘라내던 후처리 코드
  단, 이 옵션들을 지워도 나머지 로직(RAG 검색, 출처 표시)이
  깨지지 않게 조심해서 지워줘. 확신이 안 서는 줄은 지우지 말고
  나한테 물어봐줘.

[작업 3] 거절 규칙(환각 방지) 확인·추가
- 본인 앱의 시스템 프롬프트(모델에게 역할을 지시하는 문자열)를 찾아줘.
- 거기에 아래 규칙이 없으면 자연스럽게 추가해줘. 이미 비슷한 문장이
  있으면 중복 추가하지 말고 그대로 둬:
    "제공된 경조표 근거에 없는 금액·휴가일수는 지어내지 말 것.
     근거에서 값을 찾을 수 없으면 '자료에 없어 확인되지 않습니다 —
     인사팀에 문의하세요'라고 답할 것. 추정·계산으로 숫자를 만들지 말 것."
- 답변은 검색된 표 조각의 값을 그대로 옮기고, 가능하면 어느 줄을
  근거로 썼는지 출처를 함께 보여주는 기존 동작을 유지해줘.

[마무리]
- 바꾼 파일과 줄을 요약하고, 지운 코드가 있으면 왜 지웠는지 설명해줘.
- 프론트(index.html 등)에서 모델(11434/11500/ollama)을 직접 부르는
  코드가 있으면 경고만 해줘(백엔드를 거쳐야 하니까). 임의로 큰 구조를
  바꾸지는 마.
```

---

### ③ 이 프롬프트가 실제로 바꾸는 것

- 모델 호출 주소의 포트를 `:11434`(각자 raw) → `:11500`(공유 게이트웨이)으로 통일한다. IP와 모델명은 그대로.
- 코드에 박혀 있던 `think:false`·`num_predict`·`<think>` 잘라내기 후처리를 정리한다 — 이제 게이트웨이가 한곳에서 처리하기 때문.
- 시스템 프롬프트에 "근거에 없으면 지어내지 말고 '확인되지 않습니다'로 답하라"는 거절 규칙을 확인·보강한다(경조금 환각 방지).
- 프론트에서 모델을 직접 부르는 위험 코드가 있으면 경고로 알려준다.

---

### ④ 붙인 뒤 확인

1. **게이트웨이 생존 확인** — 터미널에 그대로:
   ```bash
   curl http://121.138.151.6:11500/health
   ```
   `ok`(또는 짧은 상태 JSON)가 오면 정상. 응답 없으면 강사에게 알린다.
2. **앱 기동** — 앱 폴더에서 백엔드를 띄운다(`python3 app.py` 또는 `uvicorn app:app --port 8000`). `127.0.0.1:8000` 대기 메시지가 뜨면 브라우저로 `index.html`을 연다.
3. **대표 질문 1개** — 입력창에 **"부모 사망 휴가 며칠인가요?"** → 표 값 그대로 **"휴가 5일"** 처럼 답하고, 답변에 `<think>...</think>` 같은 사고 과정이 보이지 않으면 성공. (만약 `<think>`가 보이거나 답이 비면 주소가 다시 `:11434`로 돌아간 것 — 작업 1을 다시 확인.)

---

### ⑤ 안전 (더미·비식별만, 거절 규칙)

- **개인 경조내역 입력 금지.** 직원 이름·사번·실제 신청 사유는 넣지 않는다. 질문은 "부모 사망 휴가 며칠?"처럼 **항목 단위**로만. 이름이 필요하면 "직원 A" 같은 더미로.
- **경조표는 교육용 더미만.** `DOCS`에 실제 사규 경조표(대외비 가능)를 그대로 넣어 외부로 보내지 않는다. 실데이터는 추후 내부망에서만.
- **거절 규칙 필수.** 표에 없는 금액·휴가일수는 지어내지 말고 "자료에 없어 확인되지 않습니다 — 인사팀 문의"로 답하게 한다(작업 3). 경조금은 민감한 숫자라 환각이 특히 위험하다.
- **프론트에서 모델 직접 호출 금지.** HTML/JS에서 `11434`·`11500`·`ollama`를 직접 부르지 않는다. 모델 호출은 오직 백엔드(:8000)를 거친다(보안·CORS).
- **공유 GPU 1대 — 동시성 주의.** 답변이 느리면 잠시 기다린다. 게이트웨이 주소는 외부에 공유하지 않는다.
