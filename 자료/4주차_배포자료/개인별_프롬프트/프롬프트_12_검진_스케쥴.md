## 검진-스케쥴. (검진) — 스케쥴 · 공유 API 붙이기 프롬프트

### ① 한 줄 목표
검진센터 일정표 앱(파이썬 표준 라이브러리 `http.server`, 포트 3000)에 **"일정표에 질문하기"** 한 칸을 더한다. 백엔드가 `urllib`로 공유 게이트웨이(`http://121.138.151.6:11500`)를 불러 답하게 하고, "배정표에 없으면 표에 없습니다" 거절 규칙을 시스템 프롬프트에 확실히 넣는다.

> 이 앱은 원래 AI가 없는 앱입니다. 기존 일정표·엑셀 내보내기/불러오기는 그대로 두고, "물어보면 답해 주는" AI 한 칸만 추가합니다. 모델 설정(생각 끄기·길이 상한·모델명 보정)은 게이트웨이가 알아서 처리하므로, 여러분은 **프롬프트(맥락 + 규칙)** 만 채우면 됩니다.

---

### ② 복붙 프롬프트 (Claude Code에 그대로 붙여넣기)

아래 블록을 통째로 복사해서 Claude Code 입력창에 붙여넣으세요. (손으로 코드를 고치지 않습니다. AI가 대신 고칩니다.)

```
내 검진센터 일정표 앱은 파이썬 표준 라이브러리 http.server 하나로 화면(index.html)과 API를 같은 주소(포트 3000)에서 함께 서빙하는, AI가 아직 없는 앱이야. 여기에 "일정표에 질문하기"(자연어 질의) 한 칸을 새로 붙이려고 해. requests 같은 외부 라이브러리 없이 표준 라이브러리 urllib로 공유 게이트웨이를 부르는 방식이야. 아래를 순서대로 해줘.

1) 게이트웨이 호출 헬퍼 추가
   - 본인 앱의 백엔드 파일(보통 server.py) 맨 위 import 구역에 urllib.request 를 추가해줘. (json 은 이미 import 되어 있을 거야.)
   - 아래 헬퍼 함수를 그대로 추가해줘. 주소는 반드시 포트 11500(공유 게이트웨이)이어야 해. 각자 띄우던 11434 가 아니야.

     GATEWAY = "http://121.138.151.6:11500"

     def ai_ask(system: str, user: str) -> str:
         body = {
             "model": "qwen3.6:35b-a3b",
             "messages": [
                 {"role": "system", "content": system},
                 {"role": "user",   "content": user},
             ],
             "stream": False,
         }
         req = urllib.request.Request(
             f"{GATEWAY}/api/chat",
             data=json.dumps(body).encode("utf-8"),
             headers={"Content-Type": "application/json"},
         )
         with urllib.request.urlopen(req, timeout=120) as r:
             return json.loads(r.read())["message"]["content"]

   - 중요: 게이트웨이가 생각 끄기(think:false)와 답변 길이 상한(num_predict)과 모델명 보정을 자동으로 처리해줘. 그러니 이 요청 본문(body)에 think 옵션이나 num_predict 를 절대 넣지 마. 응답에서 <think>...</think> 를 잘라내는 후처리도 넣지 마. 우리가 신경 쓸 게 없어. 모델명 qwen3.6:35b-a3b 는 그대로 둬. 게이트웨이가 실제 모델로 연결해줘.

2) 라우팅 한 줄 추가
   - 본인 앱의 do_POST 메서드를 찾아줘. 지금 /api/export-excel, /api/import-excel, /api/staff-profiles 같은 경로를 elif 로 분기하고 마지막에 else 로 404를 반환하고 있을 거야.
   - 그 else 바로 위에 아래 분기 한 줄을 끼워 넣어줘.

         elif path == "/api/ask":
             self._handle_ask()

3) 핸들러 추가 (프롬프트 TODO 포함)
   - 본인 앱의 다른 _handle_* 메서드들(예: _handle_import) 옆에 아래 핸들러를 추가해줘. 본문 읽기 _read_body() 와 JSON 응답 _send_json() 은 이미 있는 헬퍼니까 그대로 써.

     def _handle_ask(self):
         payload  = json.loads(self._read_body() or b"{}")
         question = payload.get("question", "")
         snapshot = payload.get("snapshot", {})

         system = (
             "너는 종합검진센터 일정 담당자를 돕는 비서다.\n"
             "아래 배정표(JSON)에 있는 내용만 근거로 답하라.\n"
             "표에 없는 것은 지어내지 말고 '표에 없습니다'라고만 답하라.\n"
             "답은 짧고 명확하게, 이름과 검사실·시간대 위주로 답하라.\n"
             "표 밖의 일반 상식이나 추측은 쓰지 마라."
         )
         user = (
             "[배정표]\n"
             + json.dumps(snapshot, ensure_ascii=False, indent=2)
             + f"\n\n[질문] {question}"
         )

         answer = ai_ask(system, user)
         self._send_json(200, {"answer": answer})

   - system 프롬프트에 "표에 없으면 지어내지 말고 '표에 없습니다'라고만 답하라"는 거절 규칙이 반드시 들어 있는지 확인해줘. 이건 환각(없는 사람을 배정으로 지어내기)을 막는 필수 안전장치야. 이미 위 코드에 넣었지만, 혹시 빠지거나 약하면 더 분명하게 보강해줘.

4) 화면에 질문 한 칸 추가
   - 본인 앱의 index.html 본문 맨 아래(닫는 </body> 직전 등 잘 보이는 곳)에, 질문 입력칸 + [질문] 버튼 + 답변 영역을 추가해줘. 백엔드와 같은 주소라서 fetch 는 상대경로 '/api/ask' 로 POST 하면 돼.
   - 요청 본문은 { question, snapshot } 형태야. snapshot 은 이미 화면이 들고 있는 "오늘 배정 스냅샷"(엑셀 내보내기에 쓰는 그 JSON)을 넣어줘. 어느 변수인지 바로 못 찾겠으면 일단 window.__snapshot 을 쓰도록 두고, 나중에 본인 앱의 실제 스냅샷 변수로 연결하라고 주석으로 표시해줘.

바꾼 파일과 바뀐 줄을 짧게 요약해서 알려주고, 실행해서 확인하는 방법도 알려줘. 기존 일정표·엑셀 내보내기/불러오기 기능은 절대 건드리지 말고 그대로 둬.
```

### ③ 이 프롬프트가 실제로 바꾸는 것
- 백엔드(`server.py`)에 `urllib`로 게이트웨이를 부르는 `ai_ask()` 헬퍼와 `POST /api/ask` 엔드포인트를 **새로 추가**합니다. (원래 없던 AI 기능을 붙이는 것.)
- 모델 주소를 처음부터 `:11500`(공유 게이트웨이)로 박습니다. 각자 띄우던 `:11434`가 아닙니다. 이 한 끗이 운영급 차이를 만듭니다.
- 요청 본문에 `think`·`num_predict`를 넣지 않고, `<think>` 잘라내기 후처리도 두지 않습니다. 게이트웨이가 다 대신 처리하기 때문입니다. 모델명은 그대로 둡니다.
- 시스템 프롬프트에 "배정표에 없으면 '표에 없습니다'" 거절 규칙을 넣어 환각을 막고, `index.html`에는 질문 한 칸을 더합니다.

### ④ 붙인 뒤 확인 (순서대로)
1. 게이트웨이가 살아 있는지 먼저 확인
   ```bash
   curl http://121.138.151.6:11500/health
   ```
   정상 응답이 오면 OK. 응답이 없으면 강사에게 알리고 잠시 기다리세요.
2. 내 앱(서버) 기동 — `server.py`가 있는 폴더에서:
   ```bash
   python server.py
   ```
   `서버 실행 중: http://localhost:3000` 이 보이면 정상. 브라우저에서 `http://localhost:3000` 을 엽니다.
3. 대표 질문 1개로 끝까지 확인 — 화면 없이 백엔드만 더미 스냅샷으로 테스트:
   ```bash
   curl -X POST http://localhost:3000/api/ask \
     -H "Content-Type: application/json" \
     -d '{
       "question": "오후 반휴자 누구야?",
       "snapshot": {
         "date": "2026-06-29",
         "검사실": {"내시경실":[{"name":"가가가","time":"전일"}]},
         "반휴": [{"name":"라라라","time":"오후"}]
       }
     }'
   ```
   기대: `{"answer":"라라라"}` (반휴·오후가 라라라 한 명).
   이어서 표에 **없는** 걸 물어 환각 차단을 확인하세요 → `"MRI실 담당 누구야?"` 를 물으면 기대 답은 **"표에 없습니다"**.
   답 안에 `<think> … </think>` 같은 혼잣말이 섞여 나오면 주소가 아직 `:11434`로 남은 것이니 ②의 `GATEWAY` 값을 다시 확인하세요.

### ⑤ 안전
- **더미·비식별만.** 이 앱의 `data/staff-profiles.json`에는 실명과 사번(`empId`) 자리가 있습니다 = 개인정보(PII). 테스트·시연은 반드시 더미 스냅샷으로만 하세요. 더미 이름 예: `가가가`, `나나나`, `홍길동`. 사번·전화번호는 비우거나 가짜로. 실제 직원 이름·사번을 게이트웨이(외부 공유 모델)로 보내지 마세요.
- **거절 규칙 필수.** 배정표에 없으면 지어내지 말고 "표에 없습니다"로 막혀야 합니다. 환각으로 없는 사람을 배정하면 운영 사고로 이어집니다.
- **회귀 없이.** 기존 일정표·엑셀 내보내기/불러오기는 그대로 동작해야 합니다. AI 칸은 "추가"일 뿐 기존 기능을 건드리지 않습니다.
- **공유 GPU는 1대.** 게이트웨이 뒤 GPU는 다 같이 한 대를 씁니다. 여러 명이 동시에 [질문]을 누르면 느려지니 한 명씩 천천히 시연하세요. 답이 나온 뒤 다음 질문을 보내세요.
- 게이트웨이 경유라 추론 토큰 누출은 없지만, **답을 그대로 신뢰하지 말고** 표(스냅샷)와 대조해 확인하는 습관을 들이세요.
