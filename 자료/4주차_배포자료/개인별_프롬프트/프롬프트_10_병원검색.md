## 10. 진료협력센터 — 병원검색 · 공유 API 붙이기 프롬프트

> 이 문서는 **Claude Code(AI 코딩 도구)에 그대로 붙여넣는 프롬프트**입니다.
> 손으로 코드를 고치지 않습니다. **AI에게 시켜서** 내 앱을 공유 게이트웨이(`http://121.138.151.6:11500`)에 붙입니다.

---

### ⚠️ 프롬프트 전에 — 제출 파일부터 확인 (1분, 꼭)

이번에 제출된 파일은 **`병원검색.lnk` 한 개**뿐입니다. `.lnk`는 윈도우 **'바로가기'**(실제 폴더를 가리키는 화살표)일 뿐, **안에 코드가 없습니다.** 지금 상태로는 AI가 고칠 대상이 없습니다.

**먼저 실제 프로젝트 폴더를 다시 제출하세요:**

1. 바로가기(`병원검색.lnk`)를 **더블클릭**하면 열리는 그 **폴더**가 진짜 프로젝트입니다. (보통 `app.py`·`index.html` 같은 파일이 들어 있는 폴더)
2. 그 **폴더 전체**를 압축합니다. (윈도우: 오른쪽 클릭 → 압축(ZIP) / 맥: 오른쪽 → "압축")
3. 만들어진 **`병원검색.zip`** 을 제출합니다. (`.lnk` 말고 `.zip`)

> 🔎 압축 후 크기가 **수 KB(2KB 안팎)면 또 바로가기만 담긴 것**입니다. 실제 코드 폴더는 보통 수십 KB~수 MB입니다. 너무 작으면 1번부터 다시 하세요.

코드가 들어 있는 **실제 프로젝트 폴더를 Claude Code로 연 뒤**, 아래로 진행합니다.

---

### ① 한 줄 목표

내 병원검색 앱이 모델을 부르는 **주소를 공유 게이트웨이(:11500)로 바꾸고**, 게이트웨이가 대신 처리해 주는 **군더더기 코드를 정리**하고, **"자료에 없으면 확인되지 않습니다" 거절 규칙**을 시스템 프롬프트에 넣는다.

---

### ② 복붙 프롬프트 (Claude Code에 그대로 붙여넣기)

```
너는 내 병원검색(진료협력센터 협력 병원 디렉토리) 앱을 공유 게이트웨이에 붙이는 작업을 도와줘.
아래를 순서대로, 코드를 직접 수정해 줘. 확실하지 않은 부분은 나에게 먼저 물어봐.

[배경]
- 예전에는 각자 모델 서버(raw 포트, 보통 :11434)를 직접 불렀는데,
  이제 공유 게이트웨이 http://121.138.151.6:11500 하나만 부르면 돼.
- 게이트웨이가 다음을 자동으로 처리해: 생각과정(think) 차단, 답변 길이 상한(num_predict),
  모델명 자동 보정. 그래서 내 코드에서 이 처리들은 더 이상 필요 없어.

[해줄 일]
1) 본인 앱의 백엔드(app.py 등 서버 코드)에서 모델 서버 주소를 담아 둔 줄을 찾아줘.
   - OLLAMA_URL, BASE_URL, API 주소처럼 IP(121.138.151.6)와 포트가 들어간 변수/문자열.
   - 그 주소의 포트를 11500으로 바꿔줘. IP(121.138.151.6)는 그대로 두고 포트 숫자만.
   - 채팅용·임베딩용 주소가 따로 있으면(/api/chat, /api/embeddings 등) 둘 다 :11500으로.
   - 코드 안에 11434 같은 raw 포트가 여러 군데 있으면 전부 찾아서 11500으로 통일해줘.
   - 브라우저(HTML/자바스크립트)에서 모델 서버를 직접 부르는 코드가 있으면 알려줘.
     모델 호출은 백엔드 안에서만 이뤄져야 해(프론트에서 직접 호출 금지).

2) 이제 게이트웨이가 대신 처리하므로 불필요해진 코드를 정리해줘.
   - 모델 요청 옵션에서 think(또는 "think": false 강제) 관련 처리,
     num_predict(답변 길이 상한) 강제 지정,
     응답에서 <think>...</think>를 잘라내던 후처리 코드가 있으면
     게이트웨이가 알아서 하니 제거하거나 주석으로 정리해줘.
   - 단, 지우기 전에 "이 줄을 지워도 되는지" 각각 한 줄로 설명해주고,
     기능이 바뀔 소지가 있으면 지우지 말고 나에게 물어봐.
   - 모델명(qwen 계열 채팅, bge-m3 계열 임베딩 등)은 건드리지 마. 게이트웨이가 보정해줘.

3) 시스템 프롬프트(모델에게 주는 지시문)에 거절 규칙이 있는지 확인해줘.
   - 없으면 다음 취지의 문장을 추가해줘:
     "제공된 협력 병원 자료(더미 데이터)에 근거해서만 답한다.
      자료에서 확인되지 않는 내용은 지어내지 말고
      '자료에서 확인되지 않습니다'라고 답한다.
      답할 때는 근거가 된 병원명과 전화번호 등 출처를 함께 밝힌다.
      특정 질병명을 특정 병원에 직접 연결하지 말고,
      구분(투석·호스피스·격리/감염·재활·요양 등 범주)으로만 안내한다."
   - 이미 비슷한 규칙이 있으면 중복 추가하지 말고, 부족한 부분만 보완해줘.

[마무리]
- 수정한 파일과 바뀐 줄을 요약해서 보여줘.
- 내가 확인할 수 있게, 실행 방법과 대표 질문 하나로 테스트하는 절차도 알려줘.
```

---

### ③ 이 프롬프트가 실제로 바꾸는 것

- 본인 앱의 **모델 주소 줄**의 포트를 `:11434`(각자 raw) → **`:11500`(공유 게이트웨이)** 으로 바꿉니다. IP는 그대로.
- **think 차단·`num_predict` 상한·`<think>` 잘라내기** 같은 처리를 게이트웨이에 넘기고, 내 코드에서 관련 군더더기를 정리합니다.
- 시스템 프롬프트에 **"자료에 없으면 확인되지 않습니다" 거절 규칙**과 **출처 표기·범주 안내** 규칙을 넣습니다.
- 화면 코드·검색 로직·모델명은 **그대로** 둡니다. 바뀌는 건 주소 한 줄과 정리·규칙뿐입니다.

---

### ④ 붙인 뒤 확인

**1) 게이트웨이가 살아있나** — 터미널에 그대로:

```bash
curl http://121.138.151.6:11500/health
```

`ok`(또는 짧은 상태 JSON)가 오면 정상. 응답이 없으면 강사에게 알리세요(이게 안 되면 챗봇도 안 됩니다).

**2) 내 앱 기동** — 프로젝트 폴더에서 백엔드를 띄우고(본인 코드 형태에 맞게, 예: `python app.py` 또는 `python -m uvicorn app:app --port 8000`), 확인:

```bash
curl http://127.0.0.1:8000/health
```

`{"ok": true}` 류 응답이 오면 정상. 이어서 브라우저에서 화면(`http://127.0.0.1:8000`)을 엽니다.

**3) 대표 질문 1개** — 챗 입력창에:

```
거제에서 야간투석 되는 곳 알려줘
```

관련 병원(예: 거제 카타병원 — 야간투석)을 **출처(병원명·전화)와 함께** 간결히 답하면 정상입니다. 답변에 `<think>...</think>` 같은 **생각과정이 그대로 보이면 안 됩니다.** 보이거나 답이 비면 주소가 아직 `:11434`로 남아 있을 가능성이 큽니다 — ② 프롬프트를 다시 돌려 확인하세요. 무관한 질문("수영장 어디")에 **"자료에서 확인되지 않습니다"**라고 답하면 거절 규칙도 정상입니다.

---

### ⑤ 안전

- **전부 더미·비식별만.** 협력 병원 디렉토리는 **가짜 데이터**로 실습합니다(병원명·전화·병상 모두 더미). **실제 협력기관 명단**을 코드·질문에 넣지 마세요.
- **환자정보·대외비 입력 금지.** 챗 입력창에 환자 이름·등록번호·진단명·실제 의뢰 내용을 넣지 않습니다. 질문은 "거제 투석 병원"처럼 **조건 단위**로만.
- **질병–병원 직접 연계 금지.** 특정 질병명을 특정 병원에 바로 붙이지 말고 **구분(투석·호스피스·격리/감염·재활·요양)** 으로만 안내합니다.
- **거절 규칙 유지.** 자료에 없으면 지어내지 말고 **"자료에서 확인되지 않습니다"**. 답할 땐 출처(병원명·전화)를 함께.
- **프론트/백엔드 분리.** 화면은 `http://127.0.0.1:8000` 만 부르고, 모델 서버(`121.138.151.6`)는 **백엔드가 대신** 호출합니다.
- **공유 GPU는 하나뿐.** 긴 질문을 몰아넣지 말고, 답이 끝난 뒤 다음 질문을 보내세요. 주소·모델명은 교육용이며 외부로 공유하지 않습니다.
